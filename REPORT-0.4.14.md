# DL Studio 0.4.14 — отчёт изменений

## Основа
Проект собран на базе предоставленного `DL-Studio-0.4.13.zip`. Версия обновлена в `version.txt`, `CHANGELOG.md` и `README.md` до `0.4.14`. `app/build.gradle` использует `version.txt` как единственный источник версии, поэтому `versionName` и имя архива сборки будут `0.4.14`.

## Реализовано в приложении

1. **Постоянные ID персонажей**: `grace`, `leo`, `beatrice`, `sergei`, `narrator`. Для персонажей заданы отображаемые имена, пол/тип голоса и индекс роли.
2. **Разметка реплик**: добавлены маркеры `~grace`, `~leo`, `~beatrice`, `~sergei`, `~narrator`. Старые `~f`, `~m`, `~f2`, `~m2`, `~1`…`~4` сохранены для совместимости с ранее созданными пакетами уроков.
3. **Назначение TTS**: для Grace, Leo, Beatrice и Sergei можно независимо выбрать системный голос на каждом языке в настройках. Если выбранный голос недоступен, применяется автоматический подбор подходящего голоса; старые гендерные настройки остаются поддержаны для старой разметки.
4. **Идентификация говорящего**: состояние озвучки теперь содержит ID персонажа, а не только пол. Поэтому два персонажа одного пола больше не считаются одним и тем же говорящим для анимации главных преподавателей.
5. **Реплики в уроке**: отображается имя говорящего. Для Beatrice и Sergei используется отдельный визуальный маркер с инициалом; лица Grace и Leo остаются отдельными аватарами.
6. **Настройки**: добавлены отдельные выборы голосов для Beatrice и Sergei и персональные приветствия главных преподавателей. Приветствия учитывают русский, английский и итальянский языки.

## Затронутые ключевые файлы

- `speech/Characters.kt` — реестр персонажей.
- `speech/VoiceCast.kt` — ID персонажа в роли и выбор TTS.
- `speech/Speech.kt` — передача ID текущего говорящего.
- `content/TheoryBlocks.kt` — разбор новых маркеров.
- `ui/topic/TheoryView.kt` — имя персонажа и визуальный маркер в репликах.
- `ui/components/Teachers.kt` — точная привязка анимации к персонажу.
- `ui/components/VoiceSection.kt` — персональные настройки голосов.
- `LessonLogicTest.kt` — проверки новых ID и выбора голоса.

## Проверки

- `node scripts/check.mjs` — на момент отчёта фактически падал (версия в README и порядок записей CHANGELOG); исправлено в 0.4.15.
- Отдельная компиляция Kotlin-ядра `VoiceCast` / `Characters` / парсера `TheoryBlocks` — успешно.
- Ручной исполняемый тест парсинга ID и назначения голоса — успешно.
- Полный Gradle build и Android unit tests не выполнены: Gradle Wrapper попытался скачать Gradle 8.5, но среда не имеет DNS/сетевого доступа к `services.gradle.org`. Поэтому APK не заявляется как собранная или проверенная.

## Граница реализации

В архиве DL Studio нет встроенных JSON-пакетов уроков: приложение получает темы через импорт. Новая разметка уже поддерживается приложением, но существующие импортированные пакеты нужно отдельно обновить, заменив маркеры старых реплик на постоянные ID персонажей. Второстепенные персонажи пока получают отдельные именные маркеры, а не полноценные рисованные/анимированные портреты. Для них уже работают отдельные TTS-настройки и точная идентификация говорящего.
