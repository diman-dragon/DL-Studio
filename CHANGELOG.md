# История версий

Версия повышается при каждом изменении: `package.json`, `www/js/constants/APP_VERSION.js` и значение по умолчанию в
`android/app/build.gradle` меняются вместе (это проверяет `test/version.test.js`). В CI версия берётся из тега `vX.Y.Z`.

## 2.2.0
- **Диалоги.** Новый режим «💬 Диалоги» на вкладке «Учёба». Сцена — колода типа «Диалог», реплика — карточка с ролью (1, 2 или 3). **Две роли озвучены локальными голосами** (слоты 1 и 2 со страницы «Голос»), **третья — вы** (по умолчанию роль 3; можно выбрать любую роль или «Слушаю»). Сцена идёт сама: чат реплик, каждая звучит своим голосом, дожидаемся окончания, пауза, следующая; ‹ ⏸ › — назад / пауза / пропустить, нажатие на реплику — повтор. На вашей реплике сцена ждёт: 🎤 — скажите вслух (оценка сходства с текстом, попытка в `pronunciations`, оценка в историю как `dialog`), 🔈 — образец, «Пропустить». Итог: реплик, ваших реплик, точность. Перевод под репликами включается в настройках → Учёба
- **Создание:** колода типа «Диалог» (форма колоды) и поле «Кто говорит» в карточке; импорт текста `A: фраза | перевод` (роль A / B / C или 1 / 2 / 3, заголовки `# Название`, `lang: en-US`), JSON (`kind: dialog`, `speaker`), экспорт библиотеки сохраняет роли. Повторяющиеся реплики сцены не теряются, повторный импорт не дублирует
- **Примеры карточек режима:** кнопка «Добавить пример» на пустом экране «Диалоги» добавляет три сцены (английский «В кафе» на 3 роли, «Знакомство» на 2 роли, немецкий «Im Café»); те же данные — `examples/dialogs.json`, текстовый `examples/dialog-cafe.txt`, описание формата и режима — `docs/DIALOGS.md`
- **БД v5** (миграция поверх, данные сохраняются): `decks.kind`, `cards.speaker`. Java: озвучка умеет `wait` — ответ плагина приходит, когда реплика дозвучит (`TtsProgress`)
- Код: `dialog/*`, `views/dialog{View,Roles,Chat,Controls,Done}`, `actions/dialog*` + `addSampleDialog`, `deckio/parseDialogText`, `util/speakerOf`, `tts/speechParams`, `constants/{DIALOG,SAMPLE_DIALOGS}`; «Диалоги» на хабе считают только сцены

Распознаёт встроенный распознаватель Android (сервисы Google, офлайн-пакет языка предпочтителен; язык — по голосу проекта), оценка 0–100% — сходство услышанного с текстом карточки (лучший из вариантов, по символам, слова и фразы одинаково; известная уверенность распознавателя слегка смещает оценку). «Показать текст» и «🔈 Послушать» — подсказки. Оценка карточки: ≥ 90% с первой попытки без подсказки — легко, ≥ 75% — хорошо, ≥ 55% — трудно, ниже — снова; подсказка опускает на ступень; без попытки оценки нет. Расписание карточек не двигается, пишется история (`reviews.mode = 'speak'`)
- **Каждая попытка пишется в `pronunciations`** (движок, услышанный текст, оценка, время). **Записи голоса не сохраняются**, но поле `audio` и поле `audio` в ответе плагина предусмотрены: когда понадобится, сохранение включается без миграции
- Статистика: пятая страница «Речь» — попытки за 30 дней, средняя оценка, удачные, динамика по дням, слова, которые получаются хуже всего
- Разрешение `RECORD_AUDIO` запрашивается при первом нажатии на микрофон; нет разрешения / сети / пакета языка — понятное сообщение
- Нативная часть (`speech/*`) в этой сборке проверена только чтением и тестами кода: распознавание нужно проверить на телефоне (разные языки, без интернета)
