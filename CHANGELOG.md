# История версий

Версия лежит в `version.txt` и поднимается при **каждом** изменении: меняется последняя цифра (0.0.1 → 0.0.2 → …).
Верхняя запись этого файла обязана совпадать с `version.txt` (проверяет `scripts/check.mjs`).

## 0.0.11
- GitHub Actions публикует оптимизированный release APK вместо раздутого debug APK.
- Учёба переведена на свайп между flash-карточками, без служебных надписей на карточке.
- Добавлены системные языковые пакеты TTS, выбор голоса и предпрослушка.

## 0.0.10
- Учёба: проекты → колоды → карточки, режим «все колоды» и «все карточки проекта».
- Flash-карточки с 3D-переворотом по тапу и крупной цветной нижней навигацией.

## 0.0.9
- Атомарный собственный UI: CRUD с постоянными иконками редактирования/удаления, кастомные модалки и подтверждения, современная нижняя навигация.
- Учёба, статистика и системная озвучка Android с настройками скорости и высоты голоса.

## 0.0.8
- Настройки: «Акцентный цвет» — семь цветов (фиолетовый, синий, бирюзовый, зелёный, янтарный, розовый, красный). Акцент красит основные элементы (переключатель вида, значения в настройках, кнопки, индикатор), кнопку «+» и образцы; в тёмной теме берётся светлый оттенок, в светлой — насыщенный. Выбор запоминается.
- Иконки заменены на Material Design Icons (Pictogrammers, Apache 2.0): школа, график, книга, шестерёнка (залитые у активной вкладки, контурные у остальных); проект — «перевод», колода — «карточки», карточка — «текст на карточке».
- Импорт из файла в библиотеке (кнопка над «+»): на уровне проектов файл становится новым проектом, внутри проекта — новой колодой, внутри колоды — добавляет карточки. Лицевая сторона — слово, обратная — перевод.
- Форматы: CSV/TSV/TXT (разделитель `;`, табуляция, `|`, « - », « — », « = » или запятая определяется сам; кавычки CSV; строки `#…` из Anki пропускаются), заголовок «слово;перевод;колода» (можно и по-английски) делит карточки на колоды, JSON — дерево библиотеки (`name`, `back`, `items`; id не нужны, допустимы `front`/`translation`/`decks`/`cards`). Кодировки UTF-8, UTF-16 и windows-1251 (Excel). Все id при импорте создаются заново.
- После импорта показывается итог («Добавлено: N карточек» или подсказка, если в файле ничего не нашлось).
- Тесты: разбор таблиц, JSON, кодировок, подгонка под уровень; в тестовые зависимости добавлен `org.json`.

## 0.0.7
- Исправлена сборка: в `LibraryJson` явные типы у рекурсивных функций и `put(… as Any)` (неоднозначность перегрузок `JSONArray.put`).

## 0.0.6
- Библиотека: проект (например «Английский B1») → колода → карточка; создание, правка и удаление на каждом уровне (меню «⋮», кнопка «+», подтверждение удаления).
- Вид «Карточки» (сетка) / «Список» — нажимаемый переключатель под заголовком; выбор запоминается. «Назад» поднимается на уровень выше.
- Данные лежат в `DL-Studio/library/library.json` и переезжают вместе с папкой хранения.
- Нижняя панель: крупные цветные градиентные плитки 56dp с белыми иконками Phosphor, активная светится своим цветом.

## 0.0.5
- Исправлена сборка: `FitText` сравнивает размеры шрифта по `.value` (`TextUnit` не `Comparable`, `maxOf` не компилировался).

## 0.0.4
- Шрифты: вшит Inter (текст) и Inter Display (заголовки) с полной кириллицей, единая типографика `DlTypography`.
- Переносы: только по границам слов, длинные слова — по правилам языка (`Hyphens.Auto`, `LineBreak.Paragraph/Heading`); `FitText` уменьшает шрифт, пока текст не поместится (без обрезков и разрыва слов); масштаб шрифта системы ограничен 1.15.
- Нижняя панель переделана: крупные градиентные иконки Phosphor (активная — залитая на цветной «ауре», остальные — двухтонные), подписи через `FitText`.
- Только вертикальная ориентация (`screenOrientation=portrait`).
- Плитки настроек: название сверху, значение под ним.

## 0.0.3
- Исправлена сборка: `HorizontalPager` помечен `@OptIn(ExperimentalFoundationApi::class)` (AppScaffold, PagerBack).
- Публичный постоянный ключ подписи `app/dlstudio-debug.keystore` в репозитории: новая сборка с тем же пакетом ставится поверх старой с сохранением данных (versionCode растёт с версией и номером запуска).

## 0.0.2
- Проект переименован в DL-Studio: название приложения «DL Studio», пакет `com.dlstudio.app`, папка хранения `DL-Studio`, APK `DL-Studio-<версия>`.
- Название папки в настройках берётся из `StorageLayout.ROOT` (без дубля строки).

## 0.0.1
- Новый проект с нуля: Kotlin + Jetpack Compose, сборка в GitHub Actions.
- Иконка перенесена из прежнего проекта.
- Четыре экрана со свайпом: Учёба, Статистика, Библиотека (заглушки), Настройки.
- Настройки: тема (тёмная AMOLED / светлая), язык (русский / English), папка хранения (создаётся `DL-Studio` с подпапками, при смене всё переносится, старая удаляется), о приложении.
