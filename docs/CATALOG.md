# Каталог уроков и медиа

## Уровни

```
Курс («Английский»)            поле course
└── Урок («Урок 1»)            поле group
    └── Тема (один json)       файл topics/<id>.json
        ├── теория, карточки, практика
        └── медиа: картинки, звук, видео   папка media/<id>/…
```

Это те же поля, что уже есть в json темы: в приложении (Настройки → Темы) курсы, уроки и темы показываются деревом, а для каталога
не нужно ничего дополнительного. Курс и урок не отдельные файлы, а метки на темах: поэтому добавить урок — значит добавить json тем с тем же `group`.

## Папка каталога на хостинге (https)

```
<адрес каталога>/
  course.json                  ← собирает scripts/build_content.mjs
  topics/en-l1-alphabet.json   ← тема: json без бинарных данных
  media/en-l1-alphabet/        ← медиа темы
    hello.mp3
    map.png
```

`course.json`:

```json
{
  "version": 2,
  "courses": [{ "title": "Английский", "lessons": [{ "title": "Урок 1", "topics": ["en-l1-alphabet"] }] }],
  "topics": [{
    "id": "en-l1-alphabet", "course": "Английский", "group": "Урок 1", "n": 1, "title": "Алфавит", "cards": 26,
    "pack": "topics/en-l1-alphabet.json", "size": 12921, "sha256": "…",
    "media": [{ "path": "hello.mp3", "size": 48213, "sha256": "…" }]
  }]
}
```

- `topics[]` — то, что читает приложение. `courses[]` — справочное дерево (порядок и состав); старые приложения его игнорируют.
- `sha256` каждого файла проверяется при загрузке: подмена или обрыв — тема не ставится.
- Медиа качается вместе с темой, потоком в файл (видео не лежит в памяти), уже скачанный совпавший файл пропускается.
- Тема, у которой медиа не скачалось, считается ошибкой загрузки; её можно скачать ещё раз.

## Медиа в теме

В теории — абзацы с отметкой (путь относительно `media/<id темы>/`, после ` | ` — подпись):

```
@image map.png | Британия на карте
@audio hello.mp3 | Диалог целиком
@video lesson.mp4 | Как читать звук /θ/
@audio https://example.com/dialog.mp3 | Поток без скачивания
```

- Картинки — из файла (png, jpg, webp, gif); звук (mp3, m4a, aac, ogg, wav) и видео (mp4, webm, 3gp) — из файла или потоком по https.
- Плееры встроенные в Android (MediaPlayer, VideoView), своих библиотек нет.
- Нет файла на устройстве — на странице вместо него спокойное сообщение.
- Пути только из `a-z A-Z 0-9 _ . / -`, без `..`; расширение из списка.

## Установка без каталога (zip)

```
lesson-1.zip
  topics/en-l1-alphabet.json
  media/en-l1-alphabet/hello.mp3
```

Настройки → Темы → Из файла. Папка в zip называется по `id` темы. Запись медиа до 25 МБ, весь zip до 60 МБ (он читается в память): большое видео лучше отдавать по каталогу или ссылкой https.

## Как расти дальше

- Новая тема — json в `topics/`, медиа в `media/<id>/`, затем `node scripts/build_content.mjs <папка>`.
- Новый язык — курс с другим `course` и `tag` (язык озвучки); голоса и пакеты распознавания для него появятся в настройках сами.
- Обновление: поменялся `sha256` темы — файл на хостинге новый. Сейчас приложение предлагает заново скачать тему вручную; пометка «есть обновление» — следующий шаг.
- Платные или закрытые курсы: отдельные адреса каталога; формат тот же.
