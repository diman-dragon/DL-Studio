# Правила кода (Kotlin)

1. **Сначала читай `docs/PROJECT_MAP.md`** — карта «где что»; целиком проект не читать. После изменений обновить карту.
2. **Один файл — одна операция**: один top-level тип или функция на файл, имя файла = имя объявления.
   Исключения, продиктованные фреймворком: `LingvaDatabase` (+`Schema`), Hilt-модули, `Theme.kt`.
3. **Каждое объявление где-то используется.** Неиспользуемое удаляется сразу: функции, поля моделей, параметры, константы, ресурсы, зависимости, разрешения.
4. **Без god-файлов**: ≤ 60 строк на файл (экраны — разбираются на компоненты).
5. **Без дублирования**: общее выносится в отдельный файл (общий SQL, карточка-контейнер, показ сообщений).
6. **Слои** (зависимости только вниз): `presentation → domain ← data`; `domain` — чистый Kotlin без `android.*`, покрыт юнит-тестами.
7. Схема БД v6 и `applicationId` неизменны без миграции и отдельного решения (`docs/UPDATES.md`).
