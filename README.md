# DL Studio

Курсы по темам: теория, карточки и практика. Работает без интернета. Встроенных тем нет и не будет: уроки загружаются только из файла (json или zip-пакет).
Kotlin + Jetpack Compose. Версия — в `version.txt` (сейчас 0.4.19). История изменений — в `CHANGELOG.md`.

## Как устроено

- **Старт** — самый левый экран: приветствие и фраза по тому, как человек занимался, цель дня (кольцо), «Продолжить», неделя столбиками, ранг, награды, итоги, мысль и совет дня. Всё считается из действий пользователя.
- **Карта** — сверху карточка «Продолжить», ниже тропа: темы выбранного курса идут по извилистой линии, сгруппированные по уровням. Если у тем есть предпосылки (`requires`), вместо тропы рисуется граф. Первая непройденная тема отмечена «вы здесь». Группа (например, «A1») закрывается печатью, когда пройдены все её темы.
- **Тема** — один экран с тремя этапами: теория, карточки (листаются свайпом; у тем с озвучкой есть проверка произношения по микрофону), практика. Этап, которого в теме нет, не показывается.
- **Прогресс** — уровень, XP, серия дней, печати групп.
- **Настройки** — внешний вид (тема, язык, цвет по радужной линейке), темы (из файла, удаление), языки и озвучка (языки установленных тем, голоса по полу, пакеты распознавания), сброс прогресса, «О нас».

Награды: теория +10 XP, просмотренная карточка +2, верный ответ +5, тема целиком +50. Уровень — каждые 100 XP. Повторы уже пройденного очков не дают.
Тема пройдена, когда прочитана теория, просмотрены (перевёрнуты) все карточки и верно решено 60% вопросов практики.

## Формат темы

Одна тема — один файл `<id>.json`. Несколько тем можно собрать в один zip: внутри лежит любое число таких json, приложение поставит все. `id` — только `a-z 0-9 _ -`.

```json
{
  "id": "en-to-be", "course": "English", "group": "A1", "n": 2, "title": "Глагол to be", "tag": "en-US",
  "theory": [{ "h": "Заголовок", "p": ["Абзац с **жирным** и _курсивом_."] }],
  "cards": [{ "front": "go", "pos": "глагол", "ipa": "/ɡoʊ/", "back": "идти", "forms": "go — went — gone", "example": "I go to school.", "exampleTr": "Я хожу в школу.", "note": "Для движения пешком чаще walk." }],
  "quiz": [{ "q": "Вопрос?", "a": "верный", "options": ["верный", "второй", "третий", "четвёртый"] }],
  "requires": ["en-greetings"]
}
```

- Поля карточки (только `front` и `back` обязательны, пустое поле на экране не рисуется): лицо — `front` (слово на изучаемом языке), `pos` (часть речи), `ipa` (транскрипция); оборот — `back` (перевод), `forms` (формы слова), `example` (пример на изучаемом языке), `exampleTr` (перевод примера), `note` (объяснение). Озвучка и проверка произношения — только у `front` и `example`; `say` — что произнести вместо `front`, `"mic": false` — без проверки.
- `course` — название курса; `group` — метка уровня; `n` — порядок темы внутри курса.
- `requires` — необязательно: `id` тем, которые нужно пройти раньше. Если хотя бы у одной темы группы есть `requires`, группа рисуется графом, иначе тропой.
- `tag` — язык озвучки карточек (BCP 47). Пусто — озвучки нет (например, для математики).
- В `quiz` верный ответ `a` обязан быть среди `options`, иначе вопрос отбрасывается. Порядок вариантов приложение не меняет: перемешивайте в файле.

### Виды практики (поле `t` вопроса)

| `t` | Что это | Поля |
|---|---|---|
| `choice` (по умолчанию) | выбор из четырёх | `q`, `a`, `options` |
| `listen` | на слух: фраза `say` звучит, нужно выбрать верный вариант | `say`, `a`, `options`, `q` |
| `speak` | произнести вслух, проверка микрофоном | `a` (фраза), `q`, `hint` |
| `bank` | мешок слов: собрать ответ `a` (слова через пробел), `options` — лишние слова | `q`, `a`, `options` |
| `fill` | вписать; с `say` — диктант | `q`, `a`, `alt` (другие верные), `say`, `hint` |
| `match` | соединить 2–8 пар | `q`, `pairs`: `[["A","/eɪ/"],…]` |

`listen` и `speak` показываются только в темах с `tag`. Необязательное `hint` — подсказка под вопросом.

### Медиа

В теории: `@image путь | подпись`, `@audio …`, `@video …` (путь в `media/<id темы>/` или https). Zip-пакет может нести файлы в `media/<id темы>/…`; они ставятся вместе с темой.

### Теория: значок и разметка

У страницы можно задать `"i": "🔤"` — значок в шапке карточки. Абзац начинается с отметки:
`## ` подзаголовок · `- ` пункт списка · `!tip `, `!note `, `!warn `, `!fun ` выноска ·
`~ English | перевод | что озвучить` фраза с кнопкой озвучки голосом мисс Грейс; `~grace `, `~leo `, `~beatrice `, `~john `, `~narrator ` — реплика конкретного персонажа · `| a | b` строка таблицы (первая — шапка) ·
`::v A a | эй | /eɪ/ | ay` плитка-буква (`v` гласная, `c` согласная, `b` обе). Остальное — обычный текст с **жирным** и _курсивом_.

### Карточки: `say` и `mic`

`say` — что произносит озвучка, если оно не совпадает с `front`; `"mic": false` отключает проверку микрофоном (у названий букв распознавание ненадёжно).

## Озвучка и голоса

Озвучка и проверка произношения — только встроенные средства Android. Настройки → «Языки и озвучка»: голоса движка с человеческими именами (Emma, Алёна…), прослушивание, скорость речи, кнопки «Скачать голоса» и пакетов офлайн-распознавания (Android 13+ — скачивание прямо из приложения, старее — через настройки голосового ввода).

## Установка тем

**Настройки → Темы → Из файла**: выберите json одной темы или zip-пакет (например, `DL-Studio-topics.zip`). Темы с тем же `id` заменяются, прогресс по ним сохраняется. Кнопка «Удалить все темы» очищает список после подтверждения (прогресс остаётся). Защита от «раздутых» архивов: запись до 1 МБ, не больше 2000 записей, 60 МБ всего.

## Импорт больших наборов

Наборы вида «курс → урок → карточки» (`name`, `back`, `explanation`, `example`, `hint`, `ipa`) переводятся в темы так (`ipa` → `ipa`, `explanation` и `hint` → `note`):
`node scripts/import_packs.mjs <папка с наборами> <папка для тем>`. Урок режется на темы по ~28 карточек, практика — 8 вопросов из карточек темы;
теория групп лежит в `scripts/pack_theory.mjs`. Готовые json упакуйте в zip командой `zip -r DL-Studio-topics.zip topics`.

## Языки, голоса и диалоги

- Язык темы — поле `tag` (например `en-US`). Настройки → «Языки и озвучка» показывают языки установленных тем, чего им не хватает (голос, женский или мужской голос для диалогов, пакет распознавания) и кнопку «Скачать недостающее». После установки темы из файла приложение само предлагает скачать недостающее.
- Пакеты распознавания на Android 13+ скачиваются сразу; голоса Android тихо скачать не даёт — открывается экран загрузки голосов самого движка синтеза речи.
- Пол голоса Android не сообщает. Используются только голоса с явно известным полом: `female` / `male` в названии и известные идентификаторы голосов Google (таблица в `speech/VoiceCast.kt`). Имена голосов соответствуют полу, голос выбирается самый качественный.
- Единая система персонажей (`speech/Characters.kt`): мисс Грейс и мистер Лео (преподаватели), Беатрис и Джон (ученики), Диктор. У каждого ID, имя, роль, пол голоса, цвет и портрет (открытый набор DiceBear Micah, CC BY 4.0; кадры покоя, моргания, речи, радости и огорчения делает `scripts/portraits.mjs` → `res/drawable-nodpi`, таблица `ui/components/PortraitRes.kt`). Подписи, роли и характеры — `Strings.character*` (RU/EN).
- Голоса распределяются между всеми персонажами сразу (`VoiceCast.assign`): выбранный в настройках → закреплённый прежде (персонаж не меняет голос, когда в системе появляются новые; хранится в `castAuto`) → лучший свободный голос его пола → общий голос со сдвигом тона и скорости → голос системы со своим тоном и скоростью. Два персонажа не получают один и тот же звук; пол голоса не подменяется.
- Реплика привязана к персонажу (`~id`), аватар оживает только у того, чей голос звучит (`Speaking.characterId` + метка строки). Над диалогом из нескольких реплик — «Слушать диалог»: реплики идут подряд, каждая своим голосом. Вопросы «на слух» и диктант берут голос из поля `who` (`"who": "john"`), по умолчанию — мисс Грейс.
- Знакомство: в начале курса показывается окно «Герои курса», а при первом появлении персонажа в уроке — его карточка (хранится в `met` / `introduced`; сбросить можно в настройках).
- Нет синтезатора или голоса языка: сверху появляется плашка с объяснением и кнопкой «Скачать», текст остаётся, аватары «говорят» без звука по времени.

## Проверки

- `node scripts/check.mjs` — структура (файл ≤ 350 строк, нет мёртвого кода и неиспользуемых импортов, версия совпадает в `version.txt`, `CHANGELOG.md`, `README.md`).
- `./gradlew testDebugUnitTest lint assembleRelease` — тесты и сборка (то же делает CI).

## Сборка на GitHub

Workflow лежит в `.github/workflows/build.yml` (копия — `ci/build.yml`). Если папки `.github` в репозитории нет, создайте файл с таким путём вручную: «Add file → Create new file», в имени введите `.github/workflows/build.yml` и вставьте содержимое `ci/build.yml`.

## Персонажи и разметка диалогов

Говорящий задаётся постоянным ID в начале реплики:

- `~grace English phrase | перевод` — Miss Grace (женский голос);
- `~leo English phrase | перевод` — Mr. Leo (мужской голос);
- `~beatrice English phrase | перевод` — Beatrice (женский голос);
- `~john English phrase | перевод` — John (мужской голос);
- `~narrator English phrase | перевод` — нейтральная инструкция;
- `~ English phrase | перевод` — без персонажа: голос мисс Грейс, имя в реплике не показывается.

Других отметок нет: уроки со старыми `~f`, `~m`, `~1`… не поддерживаются, такие абзацы показываются обычным текстом.

## Правило версии

Версия поднимается при каждом изменении: меняется последняя цифра.
