# DL Studio

Kotlin + Jetpack Compose. Версия — в `version.txt` (сейчас 0.2.9).

## Правило версий
Каждое изменение = +1 к последней цифре (`version.txt` и верхняя запись `CHANGELOG.md` должны совпадать).

## Правила кода (проверяет `node scripts/check.mjs`)
Файл — тематическая группа связанных деклараций (≤350 строк), ничего неиспользуемого и дублированного. Новое кладём в подходящий существующий файл, а не заводим новый на каждую функцию.

## VS Code
Расширения предложатся автоматически. Задачи: `check`, `test`, `assembleDebug`.

## Оформление
Шрифты — системные семейства Android, настраиваются по группам (интерфейс, карточка, транскрипция, пояснения, кнопки) в «Настройки → Шрифты». Размеры вне темы заданы только в `TextRole` (`ui/theme/Typography.kt`); в экранах и компонентах чисел `sp` нет. Иконки — Material Design Icons (Pictogrammers, Apache 2.0), векторы в `res/drawable/ic_*` (вкладки: `ic_tab_*_fill` / `_outline`); рисуются через `AppIcon`. Обычный текст — через `MaterialTheme.typography` (переносы по правилам включены), текст карточки и кнопок — через `CardWord`, `CardNote`, `IpaText`, `ButtonLabel`, `GroupText`, подписи в одну строку — через `FitText`. Ориентация — только портретная.

## Сборка
Push в GitHub → Actions → артефакт `DL-Studio-<версия>-release` (APK); UI-тесты идут отдельным заданием на эмуляторе.

## Экраны
Учёба (дашборд «Сегодня», расписание SM-2, оценка по поведению без кнопок, сессии и отдельный просмотр карточек как в библиотеке) · Статистика (к повтору, просрочено, серия, точность, графики) · Библиотека (проект → колода → карточка, полный CRUD, вид «карточки/список», хранится в `library/library.db`) · Настройки: тема (тёмная AMOLED/светлая), язык (RU/EN), акцентный цвет (15 вариантов, три набора по пять), папка хранения (создаётся `DL-Studio` с подпапками, при смене всё переносится, старая удаляется), «О нас». Переключение — свайп или иконки внизу; «Назад» идёт по шагу к первому экрану, затем выход.

## Режимы и настройки учёбы
В «Настройках» → «Режимы карточек» (раздел свёрнут по умолчанию) можно выключить любые из пяти упражнений (выбор перевода, выбор слова, аудирование, ввод перевода, ввод слова); хотя бы один остаётся всегда. «Помощники»: микрофон проверки произношения и анимации/поздравления. Длинные пояснения показываются в три строки и раскрываются по нажатию. Маленький динамик есть везде, где на карточке изучаемый язык: слово, пример, правильный ответ после ввода, карточки в библиотеке.

## Озвучка помедленнее
Рядом с динамиком стоит значок-черепаха (`ic_turtle`): тот же текст целиком и естественно, только медленнее (с паузой между предложениями, если их несколько) (`study/Speech.kt`, `SlowSpeech`). Темп и паузы задаются в «Настройки → Озвучка» (`StudyOptions.slowRate`, `slowPause`). Работает через `LocalSpeakSlow`, поэтому в любое место интерфейса кнопка добавляется одним `SlowButton(text)`.

## Проверка произношения
На изучаемой стороне карточки рядом с динамиком стоит зелёный микрофон. Нажали — запись пошла (кнопка красная, услышанное видно сразу), нажали ещё раз или замолчали — запись закончилась. Способы по очереди: распознавание на устройстве (Android 13+) → служба по умолчанию → служба Google напрямую → системное окно голосового ввода (как в Gemini). Свои серверы не используются. Сравнение — `study/PronounceCheck` (регистр, знаки и «to» в начале не важны; ≥85% совпавших букв — «верно», ≥60% — «почти»). Язык берётся из выбранного голоса озвучки (`en-us-x-…`), иначе по буквам слова. Разрешение микрофона спрашивается при первом нажатии. Оценка повторения расписание не меняет. Если не сработало ничего, под карточкой показывается код ошибки.

## Импорт из файла
Кнопка над «+» в библиотеке. Уровень «проекты» — файл становится проектом (имя по имени файла), «проект» — новой колодой, «колода» — карточки добавляются в неё. Строка файла = карточка: слово (лицевая сторона) и перевод (обратная), например `cat;кот`.
- CSV/TSV/TXT: разделитель определяется сам (`;`, табуляция, `|`, ` - `, ` — `, ` = `, запятая); кавычки CSV работают; строки с `#` (служебные в Anki) и строки без перевода пропускаются. Первая строка-заголовок `слово;перевод;колода` (или `front;back;deck`) задаёт колонки и делит карточки на колоды.
- JSON: массив (или один объект) `{"name": "…", "back": "…", "items": [ … ]}`; плоский массив карточек оборачивается в проект и колоду. Допустимы `front`, `translation`, `decks`, `cards`; `id` не нужны.
- Кодировки: UTF-8, UTF-16, windows-1251. Размер файла — до 10 МБ.

## Подпись и обновление
Ключ `app/dlstudio-debug.keystore` лежит в репозитории намеренно (публичный): все сборки подписаны одним ключом и ставятся поверх предыдущих без удаления. Не менять ключ и `applicationId`; `versionCode` растёт сам.

## Как работает расписание
SM-2 с тремя оценками, которые выводятся из поведения (время до переворота, подсказка): интервалы 1 → 6 → ×ease (целые дни), «Не знал» сбрасывает карточку, повтор раньше срока расписание не двигает. Логика чистая и покрыта тестами (`app/src/test/.../study`). Данные хранятся в `library/library.db`: рабочая копия во внутренней памяти, выгрузка в папку хранения отложенная.
