# DL Studio

Kotlin + Jetpack Compose. Версия — в `version.txt` (сейчас 0.0.3).

## Правило версий
Каждое изменение = +1 к последней цифре (`version.txt` и верхняя запись `CHANGELOG.md` должны совпадать).

## Правила кода (проверяет `node scripts/check.mjs`)
Один тип/функция на файл, имя файла = имя объявления, ≤60 строк, ничего неиспользуемого и дублированного.

## VS Code
Расширения предложатся автоматически. Задачи: `check`, `test`, `assembleDebug`.

## Оформление
Шрифты Inter / Inter Display (SIL OFL) лежат в `res/font`. Иконки нижней панели — Phosphor Icons (MIT), векторы в `res/drawable/ic_tab_*`. Любой текст показываем через стили `MaterialTheme.typography` (переносы по правилам включены), а подписи в одну строку — через `FitText`. Ориентация — только портретная.

## Сборка
Push в GitHub → Actions → артефакт `DL-Studio-<версия>-debug` (APK).

## Экраны
Учёба · Статистика (заглушки) · Библиотека (проект → колода → карточка, полный CRUD, вид «карточки/список», хранится в `library/library.json`) · Настройки: тема (тёмная AMOLED/светлая), язык (RU/EN), папка хранения (создаётся `DL-Studio` с подпапками, при смене всё переносится, старая удаляется), «О нас». Переключение — свайп или иконки внизу; «Назад» ведёт на первый экран.

## Подпись и обновление
Ключ `app/dlstudio-debug.keystore` лежит в репозитории намеренно (публичный): все сборки подписаны одним ключом и ставятся поверх предыдущих без удаления. Не менять ключ и `applicationId`; `versionCode` растёт сам.
