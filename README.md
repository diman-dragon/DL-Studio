# DL Studio

Курсы по темам: теория, карточки и практика. Работает без интернета, темы можно докачивать.
Kotlin + Jetpack Compose. Версия — в `version.txt` (сейчас 0.3.7). История изменений — в `CHANGELOG.md`.

## Как устроено

- **Старт** — самый левый экран: приветствие по времени суток, фраза по тому, как человек занимался, «Продолжить», мысль и совет дня.
- **Карта** — сверху карточка «Продолжить», ниже тропа: темы выбранного курса идут по извилистой линии, сгруппированные по уровням. Если у тем есть предпосылки (`requires`), вместо тропы рисуется граф. Первая непройденная тема отмечена «вы здесь». Группа (например, «A1») закрывается печатью, когда пройдены все её темы.
- **Тема** — один экран с тремя этапами: теория, карточки (листаются свайпом; у тем с озвучкой есть проверка произношения по микрофону), практика. Этап, которого в теме нет, не показывается.
- **Прогресс** — уровень, XP, серия дней, печати групп.
- **Настройки** — внешний вид (тема, язык, цвет по радужной линейке), темы (каталог, файл, удаление), сброс прогресса, «О нас».

Награды: теория +10 XP, просмотренная карточка +2, верный ответ +5, тема целиком +50. Уровень — каждые 100 XP. Повторы уже пройденного очков не дают.
Тема пройдена, когда прочитана теория, просмотрены (перевёрнуты) все карточки и верно решено 60% вопросов практики.

## Формат темы

Один файл `content/topics/<id>.json` (или zip, внутри которого такой json). `id` — только `a-z 0-9 _ -`.

```json
{
  "id": "en-to-be", "course": "English", "group": "A1", "n": 2, "title": "Глагол to be", "tag": "en-US",
  "theory": [{ "h": "Заголовок", "p": ["Абзац с **жирным** и _курсивом_."] }],
  "cards": [{ "front": "I am", "back": "я есть", "ipa": "/aɪ æm/", "example": "I am a student." }],
  "quiz": [{ "q": "Вопрос?", "a": "верный", "options": ["верный", "второй", "третий", "четвёртый"] }],
  "requires": ["en-greetings"]
}
```

- `course` — название курса; `group` — метка уровня; `n` — порядок темы внутри курса.
- `requires` — необязательно: `id` тем, которые нужно пройти раньше. Если хотя бы у одной темы группы есть `requires`, группа рисуется графом, иначе тропой.
- `tag` — язык озвучки карточек (BCP 47). Пусто — озвучки нет (например, для математики).
- В `quiz` верный ответ `a` обязан быть среди `options`, иначе вопрос отбрасывается. Порядок вариантов приложение не меняет: перемешивайте в файле.

## Каталог и загрузка по темам

`node scripts/build_content.mjs` читает `content/topics/*.json` и пишет `content/course.json` (размер и SHA-256 каждой темы).
Папку `content/` кладут на любой https-хостинг; её адрес вводят в **Настройки → Темы → Адрес каталога**.
Темы из `content/topics` также вшиты в приложение и ставятся при первом запуске.

## Проверки

- `node scripts/check.mjs` — структура (файл ≤ 350 строк, нет мёртвого кода и неиспользуемых импортов, версия совпадает в `version.txt`, `CHANGELOG.md`, `README.md`).
- `./gradlew testDebugUnitTest lint assembleRelease` — тесты и сборка (то же делает CI).

## Сборка на GitHub

Workflow лежит в `.github/workflows/build.yml` (копия — `ci/build.yml`). Если папки `.github` в репозитории нет, создайте файл с таким путём вручную: «Add file → Create new file», в имени введите `.github/workflows/build.yml` и вставьте содержимое `ci/build.yml`.

## Правило версии

Версия поднимается при каждом изменении: меняется последняя цифра.
