# DL Studio

Kotlin + Jetpack Compose. Версия — в `version.txt` (сейчас 0.1.0).

## Правило версий
Каждое изменение = +1 к последней цифре (`version.txt` и верхняя запись `CHANGELOG.md` должны совпадать).

## Правила кода (проверяет `node scripts/check.mjs`)
Один тип/функция на файл, имя файла = имя объявления, ≤60 строк, ничего неиспользуемого и дублированного.

## VS Code
Расширения предложатся автоматически. Задачи: `check`, `test`, `assembleDebug`.

## Оформление
Шрифты Inter / Inter Display (SIL OFL, подмножество латиница+кириллица) лежат в `res/font`, лицензия — `licenses/Inter-OFL.txt`. Иконки — Material Design Icons (Pictogrammers, Apache 2.0), векторы в `res/drawable/ic_*` (вкладки: `ic_tab_*_fill` / `_outline`); рисуются через `AppIcon`. Любой текст показываем через стили `MaterialTheme.typography` (переносы по правилам включены), а подписи в одну строку — через `FitText`. Ориентация — только портретная.

## Сборка
Push в GitHub → Actions → артефакт `DL-Studio-<версия>-debug` (APK).

## Экраны
Учёба (расписание SM-2, оценки «Не знал / Трудно / Знал», сессии) · Статистика (к повтору, просрочено, серия, точность, графики) · Библиотека (проект → колода → карточка, полный CRUD, вид «карточки/список», хранится в `library/library.db`) · Настройки: тема (тёмная AMOLED/светлая), язык (RU/EN), акцентный цвет (7 вариантов), папка хранения (создаётся `DL-Studio` с подпапками, при смене всё переносится, старая удаляется), «О нас». Переключение — иконки внизу; «Назад» ведёт на первый экран.

## Импорт из файла
Кнопка над «+» в библиотеке. Уровень «проекты» — файл становится проектом (имя по имени файла), «проект» — новой колодой, «колода» — карточки добавляются в неё. Строка файла = карточка: слово (лицевая сторона) и перевод (обратная), например `cat;кот`.
- CSV/TSV/TXT: разделитель определяется сам (`;`, табуляция, `|`, ` - `, ` — `, ` = `, запятая); кавычки CSV работают; строки с `#` (служебные в Anki) и строки без перевода пропускаются. Первая строка-заголовок `слово;перевод;колода` (или `front;back;deck`) задаёт колонки и делит карточки на колоды.
- JSON: массив (или один объект) `{"name": "…", "back": "…", "items": [ … ]}`; плоский массив карточек оборачивается в проект и колоду. Допустимы `front`, `translation`, `decks`, `cards`; `id` не нужны.
- Кодировки: UTF-8, UTF-16, windows-1251. Размер файла — до 10 МБ.

## Подпись и обновление
Ключ `app/dlstudio-debug.keystore` лежит в репозитории намеренно (публичный): все сборки подписаны одним ключом и ставятся поверх предыдущих без удаления. Не менять ключ и `applicationId`; `versionCode` растёт сам.

## Как работает расписание
SM-2 с тремя оценками: интервалы 1 → 6 → ×ease (целые дни), «Не знал» сбрасывает карточку, повтор раньше срока расписание не двигает. Логика чистая и покрыта тестами (`app/src/test/.../study`). Данные хранятся в `library/library.db`: рабочая копия во внутренней памяти, выгрузка в папку хранения отложенная.
