# DL Studio

Курсы по темам: теория, карточки и практика. Работает без интернета. Встроенных тем нет: темы ставят из файла (json или zip-пакет) или докачивают по каталогу.
Kotlin + Jetpack Compose. Версия — в `version.txt` (сейчас 0.4.6). История изменений — в `CHANGELOG.md`.

## Как устроено

- **Старт** — самый левый экран: приветствие и фраза по тому, как человек занимался, цель дня (кольцо), «Продолжить», неделя столбиками, ранг, награды, итоги, мысль и совет дня. Всё считается из действий пользователя.
- **Карта** — сверху карточка «Продолжить», ниже тропа: темы выбранного курса идут по извилистой линии, сгруппированные по уровням. Если у тем есть предпосылки (`requires`), вместо тропы рисуется граф. Первая непройденная тема отмечена «вы здесь». Группа (например, «A1») закрывается печатью, когда пройдены все её темы.
- **Тема** — один экран с тремя этапами: теория, карточки (листаются свайпом; у тем с озвучкой есть проверка произношения по микрофону), практика. Этап, которого в теме нет, не показывается.
- **Прогресс** — уровень, XP, серия дней, печати групп.
- **Настройки** — внешний вид (тема, язык, цвет по радужной линейке), темы (каталог, файл, удаление), сброс прогресса, «О нас».

Награды: теория +10 XP, просмотренная карточка +2, верный ответ +5, тема целиком +50. Уровень — каждые 100 XP. Повторы уже пройденного очков не дают.
Тема пройдена, когда прочитана теория, просмотрены (перевёрнуты) все карточки и верно решено 60% вопросов практики.

## Формат темы

Одна тема — один файл `<id>.json`. Несколько тем можно собрать в один zip: внутри лежит любое число таких json, приложение поставит все. `id` — только `a-z 0-9 _ -`.

```json
{
  "id": "en-to-be", "course": "English", "group": "A1", "n": 2, "title": "Глагол to be", "tag": "en-US",
  "theory": [{ "h": "Заголовок", "p": ["Абзац с **жирным** и _курсивом_."] }],
  "cards": [{ "front": "I am", "back": "я есть", "ipa": "/aɪ æm/", "example": "I am a student." }],
  "quiz": [{ "q": "Вопрос?", "a": "верный", "options": ["верный", "второй", "третий", "четвёртый"] }],
  "requires": ["en-greetings"]
}
```

- `course` — название курса; `group` — метка уровня; `n` — порядок темы внутри курса.
- `requires` — необязательно: `id` тем, которые нужно пройти раньше. Если хотя бы у одной темы группы есть `requires`, группа рисуется графом, иначе тропой.
- `tag` — язык озвучки карточек (BCP 47). Пусто — озвучки нет (например, для математики).
- В `quiz` верный ответ `a` обязан быть среди `options`, иначе вопрос отбрасывается. Порядок вариантов приложение не меняет: перемешивайте в файле.

### Виды практики (поле `t` вопроса)

| `t` | Что это | Поля |
|---|---|---|
| `choice` (по умолчанию) | выбор из четырёх | `q`, `a`, `options` |
| `listen` | на слух: фраза `say` звучит, нужно выбрать верный вариант | `say`, `a`, `options`, `q` |
| `speak` | произнести вслух, проверка микрофоном | `a` (фраза), `q`, `hint` |
| `bank` | мешок слов: собрать ответ `a` (слова через пробел), `options` — лишние слова | `q`, `a`, `options` |
| `fill` | вписать; с `say` — диктант | `q`, `a`, `alt` (другие верные), `say`, `hint` |
| `match` | соединить 2–8 пар | `q`, `pairs`: `[["A","/eɪ/"],…]` |

`listen` и `speak` показываются только в темах с `tag`. Необязательное `hint` — подсказка под вопросом.

### Медиа и каталог

В теории: `@image путь | подпись`, `@audio …`, `@video …` (путь в `media/<id темы>/` или https). Устройство каталога курсов, уроков и медиа — в `docs/CATALOG.md`.

### Теория: значок и разметка

У страницы можно задать `"i": "🔤"` — значок в шапке карточки. Абзац начинается с отметки:
`## ` подзаголовок · `- ` пункт списка · `!tip `, `!note `, `!warn `, `!fun ` выноска ·
`~ English | перевод | что озвучить` фраза с кнопкой озвучки · `| a | b` строка таблицы (первая — шапка) ·
`::v A a | эй | /eɪ/ | ay` плитка-буква (`v` гласная, `c` согласная, `b` обе). Остальное — обычный текст с **жирным** и _курсивом_.

### Карточки: `say` и `mic`

`say` — что произносит озвучка, если оно не совпадает с `front`; `"mic": false` отключает проверку микрофоном (у названий букв распознавание ненадёжно).

## Озвучка и голоса

Озвучка и проверка произношения — только встроенные средства Android. Настройки → «Озвучка и распознавание»: голоса движка с человеческими именами (Emma, Алёна…), прослушивание, скорость речи, кнопки «Скачать голоса» и пакетов офлайн-распознавания (Android 13+ — скачивание прямо из приложения, старее — через настройки голосового ввода).

## Урок 1

`node scripts/lesson1.mjs` собирает `lessons/lesson-1/DL-Studio-lesson-1.zip` (алфавит, слова, знакомство и города); ставится через Настройки → Темы → Из файла.

## Установка тем

**Настройки → Темы → Из файла**: выберите json одной темы или zip-пакет (например, `DL-Studio-topics.zip`). Темы с тем же `id` заменяются, прогресс по ним сохраняется. Кнопка «Удалить все темы» очищает список после подтверждения (прогресс остаётся). Защита от «раздутых» архивов: запись до 1 МБ, не больше 2000 записей, 60 МБ всего.

## Импорт больших наборов

Наборы вида «курс → урок → карточки» (`name`, `back`, `explanation`, `example`, `hint`, `ipa`) переводятся в темы так:
`node scripts/import_packs.mjs <папка с наборами> <папка для тем>`. Урок режется на темы по ~28 карточек, практика — 8 вопросов из карточек темы;
теория групп лежит в `scripts/pack_theory.mjs`. Готовые json упакуйте в zip командой `zip -r DL-Studio-topics.zip topics`.

## Каталог и загрузка по темам

Для докачки по сети: `node scripts/build_content.mjs <папка>` читает `<папка>/topics/*.json` и пишет `<папка>/course.json` (размер и SHA-256 каждой темы).
Папку кладут на любой https-хостинг; её адрес вводят в **Настройки → Темы → Адрес каталога**.

## Проверки

- `node scripts/check.mjs` — структура (файл ≤ 350 строк, нет мёртвого кода и неиспользуемых импортов, версия совпадает в `version.txt`, `CHANGELOG.md`, `README.md`).
- `./gradlew testDebugUnitTest lint assembleRelease` — тесты и сборка (то же делает CI).

## Сборка на GitHub

Workflow лежит в `.github/workflows/build.yml` (копия — `ci/build.yml`). Если папки `.github` в репозитории нет, создайте файл с таким путём вручную: «Add file → Create new file», в имени введите `.github/workflows/build.yml` и вставьте содержимое `ci/build.yml`.

## Правило версии

Версия поднимается при каждом изменении: меняется последняя цифра.
